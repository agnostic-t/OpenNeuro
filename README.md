# OpenNeuro

Данный репозиторий является а-ля учебником для введения в нейробиологию (написано мной лично), источником является интернет. Так как я сам только учусь, то некоторые моменты могут быть не точными. 

Надо также понимать, что сугубо биологические и химические термины могут быть опущены, в угоду понимания самих принципов, вместо того, чтобы зацикливаться на том, какой именно фермент на что именно воздействует.

Репозиторий разделен на 3 папки:

- `code`: содержит код для симуляции SNN (только PoC)
- `docs`: содержит сгруппированные статьи по определенным темам
- `framework`: содержит библиотеку и примеры использования

Русский язык выбран как основной, т.к. для меня легче его понимать. Если проект вырастет, то будет разделение на EN и RU версию.

## Библиотека OpenNeuro

Предоставляет интерфейс для удобного построения SNN через любые из 5 доступных моделей симуляции нейронов (LIF, EIF, AdEx, Izhikevich, Hodjkin-Haxly)

Сборка примера:

```sh
# 1. Соберите библиотеку

cd ./framework
make -C ./openneuro

# 2. Соберите пример
cd ./examples
make

# Запуск
./bin/00_models_example_test
```
